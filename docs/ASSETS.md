# Asset attribution and visual references

RentEase retains the bundled Horizon Estate photography and visual assets as a design foundation for this frontend demonstration. The codebase is released under the [MIT License](../LICENSE); third-party image, font, and icon licenses remain with their respective works.

## Images

- `public/images/hero/` supplies the existing homepage imagery.
- `public/images/properties/` supplies sample rental listing, detail, and property-editor images.
- Unused Horizon Estate agent, journal, service, and unrelated listing images were removed after confirming there were no active code or documentation references.
- `public/showcase/` contains screenshots from the original Horizon Estate site. They are retained as a visual reference, not presented as current RentEase screenshots.

Bundled photography is illustrative only. Replace it with appropriately licensed, authorized assets before using the application for real listings.

## Typography and icons

- **Manrope** is loaded through `next/font/google` in `src/app/layout.js` and is distributed under the SIL Open Font License.
- **Lucide React** supplies the interface icons and is distributed under its ISC license.

See [Project overview](PROJECT_OVERVIEW.md) for the adapted visual foundation and [Features](FEATURES.md) for current image usage.
